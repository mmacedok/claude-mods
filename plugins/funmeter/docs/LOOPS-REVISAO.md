## Redraw continuity

emFase at hooks/register.tsx:638 already computes (ms / 1000) % Number(d) for each element's own dur; it was correct and is unchanged. comFase at :652 retains identical source bytes for an unchanged raw SVG, preventing unnecessary image reloads. Changed raw sources receive the current phase. No begin attribute was added to a raw drawing; the existing helper remains the sole phase injector.

The checker tested 678 consecutive-redraw pairs, including epoch-sized clocks and cycle boundaries, and 6,150 individual SMIL phase comparisons. It verifies cached byte reuse, changed-source phase advancement by 73 ms, a single begin attribute, each element's own duration and CSS gl/br/bo phases. br uses its full 10 s alternate cycle. These are programmatic checks; live host repaint behavior was not observed.

## Checks and reproduction

Run with Node 24 or newer:

~~~text
node plugins/funmeter/docs/checar-loops.cjs --json plugins/funmeter/docs/loops-depois.json
~~~

The script follows f4-previa.cjs: slices only pure drawing code, strips TypeScript with node:module, executes it in node:vm, calls the drawing functions, and parses the resulting SVG strings. It checks all indefinite-animation templates, endpoint/wrap/invisibility conditions, internal jumps, path command/argument structure, keyTimes/keySplines, matching gate durations, raw begin absence, and phased SVG size. It was executed before and after through Node REPL using its exported runCheck, since starting a separate process was denied.
